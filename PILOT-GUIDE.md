# Flowdesk Controlled Pilot Guide

## Goal
Ask one business owner to test Flowdesk with fictional data before any real customer data is entered.

## 30-minute session
1. Register a test account (3 min).
2. Explore Service Business and Creator Hub (3 min).
3. Add and edit a booking/client (5 min).
4. Add and edit a brand deal (5 min).
5. Add income and expense transactions; check totals (5 min).
6. Search, delete a sample record and export workspace data (4 min).
7. Collect feedback and note failures (5 min).

## Pass criteria
- The user can complete core tasks without developer help.
- Records persist after signing out and back in.
- Dashboard totals match the test transactions.
- Switching workspaces shows the correct records.
- A second test account cannot access the first account's data.
- No critical data loss, unauthorized access or broken core workflow occurs.

## Safety
Use fictional records during the pilot. Do not use real customer or financial information until deployment security, backups and recovery have been verified.

## Decision
Record each issue with steps to reproduce, expected behavior, actual behavior and severity. Fix critical and high-severity issues before considering a paid trial.
