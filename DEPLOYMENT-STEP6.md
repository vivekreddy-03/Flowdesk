# Step 6 — Deployment Guide

## Render Blueprint
1. Push the repository to GitHub.
2. In Render, choose **New → Blueprint** and select this repository.
3. Review the service and persistent disk plan/costs before approving.
4. Confirm `SESSION_SECRET` is generated by the host and `DATA_DIR=/var/data`.
5. Wait for deployment and the `/api/health` check.

## Post-deployment smoke test
- Open the public URL over HTTPS.
- Register a test account using fictional data.
- Sign out and sign in again.
- Create, edit, search and delete a sample record in each workspace.
- Confirm data remains after a service restart.
- Confirm a second account cannot read the first account's records.
- Create a backup and perform a restore test before using real business data.

## Important limitations
A successful local run does not prove a successful hosted deployment. This document is a checklist, not evidence that the app is already live. Configure off-site backups and verify recovery on the selected host before a business pilot.
